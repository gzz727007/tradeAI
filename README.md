# A股可转债“多策略对决 + AI智能体投研”系统 (tradeAI)

基于 **FastAPI + React 19 + Tailwind CSS** 商业级全栈架构与 **LangGraph 多智能体协同状态图** 的 A 股可转债量化投研交易与回测终端。

---

## 🌟 核心架构与功能亮点

1. **商业级全栈架构 (FastAPI + React 19 + Tailwind CSS + ECharts)**：
   - **后端 (FastAPI)**：纯净异步 RESTful API 与实时 WebSocket 智能体流式通信，解耦计算与渲染，告别页面卡顿与全量重跑；
   - **前端 (React SPA)**：毫秒级响应、零整页刷新、自包含高信息密度卡片网格、原生浮层弹窗、ECharts 动态回测曲线；
   - **一体化托管**：FastAPI 后端原生集成前端生产打包构建，单一端口即可直接访问完整金融看板。

2. **多策略并行竞技场 (Strategy Tournament)**：
   - 内置 **中证转债基准 (000832)**、**经典双低轮动**、**高 YTM 深度防御**、**小盘高弹性进攻**、**AI 多智能体增强** 策略；
   - 支持自定义策略参数边界与大模型自主挖掘新策略；
   - 在同一条历史时间线上并行回测对决，自动计算年化收益率 (CAGR)、最大回撤 (MaxDD)、夏普比率 (Sharpe) 和卡玛比率 (Calmar)。

3. **双轨账户管理体系 (前向赛马模拟盘 + 实盘多账号管家)**：
   - **实盘模拟竞技场 (Paper)**：每个策略独立配置虚拟资金，前向实盘行情赛马，评估策略实盘跟踪能力；
   - **实盘多账号管家 (Real)**：支持不同策略绑定独立实盘账户，散户半自动记账，自动核算每日净值与持仓重估。

4. **LangGraph 多智能体协同会诊 (Multi-Agent System)**：
   - **量化初筛 Agent**：实时从全市场 1,059 只转债中圈定候选标的；
   - **信用排雷 Agent (Qwen 28B)**：专职审查发债公司基本面、债务违约与退市风险，拥有一票否决权 (VETO)；
   - **正股动量 Agent (Gemini 3.8 Flash)**：快速分析正股题材热度与进攻弹性；
   - **条款博弈 Agent (Gemini 3.1 Pro)**：深度推演大股东转股诉求、下修到底概率与强赎风险；
   - **投资总监 Agent (PM)**：汇总三方研判，执行信用一票否决，输出最终组合评级与配置建议；
   - **圆桌辩论室**：选择任意转债，实时查看 4 大专家多空交锋实录。

## 🚀 快速上手指南

### 方式一：Windows 一键交互菜单 (双击即用，推荐)
直接在项目根目录下**双击运行 `start.bat`**：
- 输入 `1`：启动**商业级全栈金融终端**（FastAPI + React），自动在浏览器打开 `http://localhost:8088`；
- 输入 `2`：启动 Streamlit 轻量看板 (`http://localhost:8501`)；
- 输入 `3`：运行今日实时 LangGraph 投研并生成组合建议（推送飞书/微信）；
- 输入 `4`：运行多策略历史回测对决命令行版；
- 输入 `5`：使用 Docker 构建并启动。

### 方式二：手动启动商业级全栈终端
```bash
# 启动 FastAPI 后端服务 (一体化托管前端 SPA，端口 8088)
.\.venv\Scripts\python.exe -m uvicorn server.main:app --host 0.0.0.0 --port 8088

# 访问地址：
# • 前端金融大屏: http://localhost:8088
# • 交互式 API 文档 (Swagger UI): http://localhost:8088/docs
```

前端源码位于 `frontend/` 目录，若需进行前端热重载开发：
```bash
cd frontend
npm.cmd run dev
# 访问开发热更新页面: http://localhost:3000
```
